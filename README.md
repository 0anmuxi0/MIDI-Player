# MIDI 可视化播放器

把 MIDI 变成看得见的音乐：音符从上方落下、撞上判定线时亮起，配合高品质采样音源实时播放。

> 本仓库不存放界面截图与视频，实际效果直接下载体验即可。

---

## 下载与安装

到 [**Releases**](https://github.com/0anmuxi0/MIDI-Player/releases) 页面下载 `MIDI.Player.exe`。

- **单文件，无需安装**：双击即可运行，音色库已内置
- 大小约 93 MB，**启动约 0.1 秒**
- 系统要求：Windows 10 (1809+) / Windows 11

> 首次运行如果提示缺少 WebView2 运行时，装一下微软官方的
> [WebView2 Runtime](https://developer.microsoft.com/microsoft-edge/webview2/)（Windows 11 已自带）。

---

## 主要功能

**看得见的演奏**
- 音符瀑布流：水平、垂直两种方向，判定线位置可调
- 粒子特效、音符发光、屏幕震动（幅度会按窗口分辨率自动缩放，高分屏同样明显）
- 音名标注、小节线、播放进度、循环播放

**好听的音色**
- 内置三套音色库（FluidR3_GM / FatBoy / Salamander），无需额外下载
- 逐轨控制：单独开关、调音量、换音色（GM 128 种 + 采样 + 合成器）

**顺手的细节**
- 浅色 / 深色 / 跟随系统，**切换即时生效**（标题栏也会跟着变）
- 设置项按窗口宽度自动排布（宽屏最多 4 列）
- 全屏时只留画面，其它界面全部隐藏
- 画面高度可以拖拽调整
- 所有设置自动保存，下次打开照旧

## 使用

| 操作 | 说明 |
|---|---|
| 打开 MIDI | 点「上传 MIDI 文件」，或把 `.mid` 文件直接拖进窗口 |
| 播放 / 暂停 | 点「播放」，或按 **空格** |
| 重置 | 按 **R** |
| 全屏 | 画布右上角按钮，或按 **F11** |
| 退出全屏 | **ESC** |
| 调整画面高度 | 鼠标移到画面底边，出现拖动条后上下拖动 |
| 单轨控制 | 在「音轨」区域逐轨开关、调音量、换音色 |

## 设置

所有设置改动都会**自动保存**，重开程序自动恢复，包括：音量、播放速度、瀑布流速度、判定线位置、
方向、粒子与发光效果、震动幅度、画布高度、窗口大小、主题。

如果想恢复默认，删除注册表项 `HKEY_CURRENT_USER\Software\MIDIPlayer` 即可。

**关于自动更新**：程序启动后会检查一次新版本。如果发现更新，会询问是否下载；
下载完成后可选择立即重启完成更新。（不想让它检查，可在注册表配置里把 `autoUpdate` 设为 `0`。）

## 常见问题

**没有声音？**
先确认窗口状态提示正常，并检查系统音量。首次播放某个乐器时有几秒的采样准备时间属正常。

**启动没反应 / 提示缺少组件？**
通常是缺少 WebView2 运行时，按上面「下载与安装」里的链接安装即可。

**画面卡顿？**
在设置里调低「粒子数量」，或关闭「粒子特效」「屏幕震动」。
